# 오늘의 타로 원고 가이드

`tools/tarot_readings_ko.json`은 정방향 카드 78장의 한국어 일일 운세 원고다. 카드 ID는 메이저 아르카나 `major-00`부터 `major-21`, 마이너 아르카나 `cups-01`부터 `cups-14`, `pentacles-01`부터 `pentacles-14`, `swords-01`부터 `swords-14`, `wands-01`부터 `wands-14`까지 사용한다. 마이너의 `01`은 에이스, `11`은 페이지, `12`는 나이트, `13`은 퀸, `14`는 킹이다.

## 데이터 계약

- 최상위 JSON object의 key가 카드 ID다.
- 각 카드 object는 `headline`, `flow`, `caution`, `action`을 가지며, 선택적으로 양의 정수
  `copy_version`을 둘 수 있다. 생략하면 버전 1이다.
- 네 값은 모두 1~2개의 string을 담은 array다. array의 원소 하나가 화면의 한 줄이다.
- `headline` 한 줄은 display cell 22 이하, 나머지 한 줄은 display cell 32 이하다. 이 상한은
  Noto Sans KR 28 px/16 px의 실제 LVGL glyph 폭을 310 px/263 px 고정 행에서 검증한 값이다.
- display cell은 공백 문자를 1, 잉크가 있는 모든 글자를 2로 센다. 라틴 `W`도 한글 음절만큼
  넓게 그려지므로 일반 East Asian Width 규칙을 쓰면 합법적인 줄이 잘릴 수 있다.
- 줄바꿈은 원고에서 확정한다. 소비자는 문자열을 합치거나 다시 나누지 않는다.
- 원고는 정방향 전용이다. 역방향 의미는 이 파일에 섞지 않는다.

검사식의 기준 구현은 다음과 같다.

```python
def tarot_display_cells(text: str) -> int:
    return sum(1 if ch.isspace() else 2 for ch in text)
```

## 문체

- 화면에서 한 번에 읽히는 짧은 현재형 문장을 쓴다.
- 사용자가 오늘 할 수 있는 관찰이나 행동을 능동형으로 제시한다.
- `flow`에는 카드의 상징이나 전통 의미가 드러나는 장면을 담는다.
- `caution`은 위험을 과장하지 않고 조절할 지점을 말한다.
- `action`은 작고 구체적인 한 가지 행동으로 끝낸다.
- 같은 문장 뼈대와 추상 명사의 반복을 줄이고 카드마다 다른 동사와 사물을 쓴다.
- 조언은 차분하고 선택 가능하게 쓴다. 결과를 보장하거나 운명을 단정하지 않는다.

## 금칙과 주의

- 공포 조장: `재앙`, `파멸`, `불행이 닥친다`, `반드시 잃는다`처럼 위협하지 않는다.
- 확정적 예언: `무조건`, `틀림없이`, `반드시 성공`, `운명이다`처럼 결과를 고정하지 않는다.
- 의료·법률·금융 판단: 진단, 처방, 소송 전략, 투자 종목이나 수익 보장을 제시하지 않는다.
- 관계 단정: 상대의 속마음, 배신, 이별, 임신 등을 사실처럼 말하지 않는다.
- AI식 추상어: `내면의 여정`, `우주의 에너지`, `새로운 가능성`, `진정한 자아`, `긍정적 변화`를 만능 결론처럼 반복하지 않는다.
- 카드의 어두운 의미도 생활 언어로 번역한다. 예를 들어 탑은 붕괴를 예언하지 않고 이미 흔들리는 전제를 점검하게 한다.
- 원전 의미 데이터는 사실 확인에만 참고하고 문장을 번역하거나 복사하지 않는다. 한국어 원고는 카드 상징을 바탕으로 새로 쓴다.

## 검토 체크리스트

1. 78개 ID가 빠짐없이 한 번씩 있는가.
2. 네 필드가 모두 1~2줄의 문자열 배열인가.
3. display-cell 한도를 지켰는가.
4. 카드 고유 상징이 적어도 한 필드에 보이는가.
5. 사용자를 겁주거나 결과를 단정하지 않는가.
6. 행동 문장이 오늘 바로 실행할 만큼 구체적인가.
7. 가까운 카드끼리 같은 핵심 문구를 재사용하지 않았는가.
